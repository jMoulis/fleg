# 15 — Multi-store analytics

Network dashboard:
- total CA/margin,
- target attainment,
- store ranking,
- anomalies,
- normalized productivity.

Benchmark groups can represent similar format, F&L area, revenue band or manager-selected peers.

Never rank only raw CA. Prefer normalized indicators where data exists.

NET-01 uses confirmed effective commercial meter as its first normalization basis. Stores whose latest layout geometry is not confirmed are excluded from the ranking without being excluded from network totals. Missing markdown, objectives or prior-year facts stay explicitly partial; the network aggregate for that metric remains unknown until every store with current sales is covered.

Cross-store product intelligence examples:
- same SKU performance normalized by effective display space,
- markdown-rate outliers,
- TG/event uplift comparison,
- assortment gaps.

Cross-store permissions are explicit.

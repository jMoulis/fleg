# 01 — Product Requirements Document

## Problem
F&L managers have sales, quantity and theoretical margin data but decisions remain fragmented: assortment, ordering, display space, TG/endcaps, seasonality, markdown and margin are rarely connected.

## Users
### Organization admin / owner
Network overview, comparisons, targets, store access.
### Store director
Store economics, department performance, action plans.
### F&L department manager
Daily/weekly execution: products, space, TG, markdown, forecast.
### Employee
Operational tasks and limited data entry.
### Viewer
Read-only analytics.

## Jobs to be done
- Know what to push / maintain / reduce.
- Understand why CA or margin changed.
- Forecast next period.
- Allocate scarce display space.
- Plan TG/endcaps.
- Identify markdown/waste destroyers.
- Compare comparable stores.
- Record decisions and measure impact.
- Ask AI grounded questions about the store/network.

## MVP
1. Auth + multi-store.
2. Mercalys import.
3. Store/network dashboard.
4. Product matrix.
5. Forecast + seasonality.
6. ABC/XYZ.
7. Store layout and display allocation.
8. TG planner.
9. Markdown.
10. Decision log.
11. AI copilot.
12. Settings/targets.

## Non-goals MVP
- Autonomous purchasing.
- ERP replacement.
- Supplier ordering integration.
- Computer vision auto-planogram.
- Exact causal attribution from sparse monthly data.

## Success metrics
- import-to-insight < 3 minutes,
- 100% store-isolation test pass,
- >80% of top recommendations explainable from displayed evidence,
- manager can produce weekly action plan < 10 minutes,
- space allocation totals never exceed physical capacity,
- recommendation acceptance/rejection is measurable.
